# Verify the square example in the other order

We again integrate $f(x,y)=x^2y+xy^3$ over $0\le x\le1$, $0\le y\le1$, this time using vertical slices. A correct reversal must give the same value, $7/24$.

## Write the new order completely

$$
I=\int_0^1\int_0^1(x^2y+xy^3)\,dy\,dx.
$$

The limits happen to be identical because this is a unit square. The important change is that $dy$ is now next to the integrand, so $y$ is integrated first.

## Treat x as constant in the inner integral

The coefficients $x^2$ and $x$ stay fixed:

$$
\int_0^1(x^2y+xy^3)\,dy
=\left[\frac{x^2y^2}{2}+\frac{xy^4}{4}\right]_0^1
=\frac{x^2}{2}+\frac x4.
$$

We have obtained the area of the vertical cross-section at coordinate $x$.

## Add every cross-section

$$
\begin{aligned}
I&=\int_0^1\left(\frac{x^2}{2}+\frac x4\right)dx\\
&=\left[\frac{x^3}{6}+\frac{x^2}{8}\right]_0^1\\
&=\frac16+\frac18=\boxed{\frac7{24}}.
\end{aligned}
$$

The intermediate expressions differ between the two orders because they describe different slices. The final total agrees because both include precisely the same volume.

## What this says about a density

The given function is nonnegative, but its total integral is $7/24$, not one. If we wanted to use this surface as a joint density on the unit square, we would normalize it:

$$
f_{X,Y}(x,y)=\frac{24}{7}(x^2y+xy^3),\qquad 0<x<1,\ 0<y<1.
$$

Multiplying every height by $24/7$ changes the total volume from $7/24$ to one, without changing the relative weighting of points in the square.
