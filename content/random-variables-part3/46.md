# Build the complete treatment-count probability table

For four independent patients with category probabilities $0.3$, $0.5$, and $0.2$, every possible triple $(x,y,z)$ satisfies $x+y+z=4$. The table below lists all 15 triples and their probabilities, grouped by the number $z$ with no change.

## Generate each row systematically

Fix $z$. Then $x$ can run from 0 to $4-z$, and $y=4-z-x$ is forced. For each row use

$$
p(x,y,z)=\frac{24}{x!y!z!}(0.3)^x(0.5)^y(0.2)^z.
$$

| Cures $x$ | Reduced pain $y$ | No change $z$ | Probability |
|---:|---:|---:|---:|
| 0 | 4 | 0 | 0.0625 |
| 1 | 3 | 0 | 0.1500 |
| 2 | 2 | 0 | 0.1350 |
| 3 | 1 | 0 | 0.0540 |
| 4 | 0 | 0 | 0.0081 |
| 0 | 3 | 1 | 0.1000 |
| 1 | 2 | 1 | 0.1800 |
| 2 | 1 | 1 | 0.1080 |
| 3 | 0 | 1 | 0.0216 |
| 0 | 2 | 2 | 0.0600 |
| 1 | 1 | 2 | 0.0720 |
| 2 | 0 | 2 | 0.0216 |
| 0 | 1 | 3 | 0.0160 |
| 1 | 0 | 3 | 0.0096 |
| 0 | 0 | 4 | 0.0016 |

## Check one row with repeated categories

For $(x,y,z)=(2,1,1)$, the coefficient is

$$
\frac{4!}{2!1!1!}=12.
$$

A specified arrangement has probability $0.3^2\cdot0.5\cdot0.2=0.009$. Thus the row probability is $12(0.009)=0.108$.

## Group the rows by Z

Adding within each group gives

| Number unchanged $z$ | Total probability |
|---:|---:|
| 0 | 0.4096 |
| 1 | 0.4096 |
| 2 | 0.1536 |
| 3 | 0.0256 |
| 4 | 0.0016 |

These totals sum to one. They also form the binomial distribution with four trials and unchanged probability $0.2$.

## Why there are 15 triples

For $z=0$, there are 5 possible $x$ counts. For $z=1$, there are 4; then 3, 2, and 1. Thus $5+4+3+2+1=15$ possible triples.

The 15 rows are not equally likely. For example, $(0,4,0)$ has probability $0.5^4=0.0625$, while $(0,0,4)$ has probability $0.2^4=0.0016$. Listing possible outcomes does not establish equal probabilities.
