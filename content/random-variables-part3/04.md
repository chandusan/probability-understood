# A rectangle gives constant integration limits

Suppose the event region is $A=\{(x,y):a\le x\le b,\ c\le y\le d\}$. It is a rectangle: every allowed $y$ has the same horizontal range $a\le x\le b$, and every allowed $x$ has the same vertical range $c\le y\le d$.

## Translate the geometry into an integral

Choose a value of $y$ between $c$ and $d$. Holding that value fixed, move horizontally through the rectangle from $x=a$ to $x=b$. This gives

$$
\int_a^b f(x,y)\,dx.
$$

Then include every horizontal slice by integrating over $y$:

$$
\boxed{\iint_A f(x,y)\,dx\,dy
=\int_c^d\left[\int_a^b f(x,y)\,dx\right]dy.}
$$

The integral nearest the function is evaluated first. Here $dx$ makes $x$ the inner variable and $dy$ makes $y$ the outer variable.

## The other order covers the same rectangle

If we instead use vertical slices, we obtain

$$
\iint_A f(x,y)\,dx\,dy
=\int_a^b\left[\int_c^d f(x,y)\,dy\right]dx.
$$

For a nonnegative density these orders give the same probability. They also agree for the continuous functions on bounded regions used in these examples.

## Match each limit to its variable

For the region $1\le x\le4$, $2\le y\le5$, the two expressions are

$$
\int_2^5\int_1^4 f(x,y)\,dx\,dy,
\qquad
\int_1^4\int_2^5 f(x,y)\,dy\,dx.
$$

Reversing the order means moving each variable together with its corresponding limits. It does not mean keeping the bounds fixed and changing only $dx\,dy$ into $dy\,dx$.
