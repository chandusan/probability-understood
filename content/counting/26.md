# Divide out the orderings you do not care about

Sometimes it is easier to count detailed descriptions first, then group together descriptions that represent the same outcome. The combination formula works because every selected set has exactly the same number of ordered descriptions.

## Count first with order included

Select $k$ distinct objects from a pool of $n$, without replacement, and put them into $k$ positions. The permutation count is

$$
P(n,k)=\frac{n!}{(n-k)!}.
$$

Now erase the position labels and keep only the selected set. Several ordered selections collapse into each unordered set. How many?

For the set $\{A,B,C\}$, the ordered descriptions are

$$
ABC,\ ACB,\ BAC,\ BCA,\ CAB,\ CBA.
$$

There are $3!=6$. Every other three-element set also has six descriptions.

## Equal-sized groups justify the division

For a general $k$-element set, choose which of its members appears first in $k$ ways, which appears second in $k-1$ ways, and so on. This gives $k!$ orders, regardless of which set was selected.

Therefore

$$
P(n,k)=\binom nk\,k!,
$$

and so

$$
\boxed{\binom nk=\frac{P(n,k)}{k!}=\frac{n!}{k!(n-k)!}.}
$$

The phrase “order does not matter” tells us to group descriptions. The stronger fact **“every group contains exactly $k!$ descriptions”** is what licenses division by $k!$.

<details markdown="1"><summary>Why nothing is lost or counted twice</summary>

Every ordered selection produces exactly one underlying set, so it belongs to exactly one group. Every $k$-element set can be arranged, so no set is missing. Finally, arranging its $k$ distinct elements produces precisely $k!$ different ordered selections.

Thus the ordered selections are partitioned into equal-sized groups. Counting all selections is the same as counting groups and multiplying by their size. This is a proof of the formula, rather than a rule based on matching words in a question.

</details>

## A warning about repeated objects

If repetition is allowed, the groups need not have equal size. The repeated selection $AAA$ has one ordering, while $AAB$ has three and $ABC$ has six. Dividing all ordered sequences by $3!$ would treat unequal groups as equal and fail.

For example, two categories and three draws give $2^3=8$ sequences but four unordered multisets: $AAA,AAB,ABB,BBB$. The answer is not $8/6$. Stars and bars will count these repeated selections directly.

## Check your understanding

There are 120 ordered ways to select three distinct objects from six. How many three-element subsets are there, and why is the divisor 6 rather than 3?

<details markdown="1"><summary>Reveal the grouping argument</summary>

Each selected triple has $3!=6$ orderings, not merely three. Therefore

$$
\binom63=\frac{120}{6}=20.
$$

The divisor counts complete arrangements of the three selected objects. Choosing only which object comes first would leave two possible orders for the remaining two objects, so it would not remove all ordering information.

</details>
