# Make all 24 arrangements visible

Four distinct objects have $4!=24$ orderings. Listing them systematically shows why the factorial works: choose a first letter, then list every ordering of the remaining three without omissions or repetitions.

## Count before listing

For $\{A,B,C,D\}$, there are four choices for the first position, three for the second, two for the third, and one for the fourth:

$$\boxed{4!=4\cdot3\cdot2\cdot1=24.}$$

The last factor of one records the final forced placement. A forced step does not add new possibilities, which is why multiplying by one leaves the count unchanged.

## All arrangements in four disjoint groups

Each row fixes the first letter. The six entries in that row arrange the remaining three letters.

| First letter | All six continuations |
|---|---|
| $A$ | $ABCD,\ ABDC,\ ACBD,\ ACDB,\ ADBC,\ ADCB$ |
| $B$ | $BACD,\ BADC,\ BCAD,\ BCDA,\ BDAC,\ BDCA$ |
| $C$ | $CABD,\ CADB,\ CBAD,\ CBDA,\ CDAB,\ CDBA$ |
| $D$ | $DABC,\ DACB,\ DBAC,\ DBCA,\ DCAB,\ DCBA$ |

Within the first row, the second letter can be $B,C,D$. Once those first two letters are fixed, the last two can appear in either order. Thus each row contains $3\cdot2\cdot1=6$ entries.

The groups are disjoint because a sequence cannot begin with two different letters. They exhaust the possible orderings because every sequence begins with one of $A,B,C,D$. Adding the four groups gives $6+6+6+6=24$.

## Distinguish arranging from choosing

Every entry uses the same four-element set. The difference lies in where each object is placed. If the question only asked which four objects are selected from this exact set, there would be one answer: the whole set. Arranging that chosen set produces $24$ different ordered results.

Likewise, $ABCD$ and $BACD$ are different sequences even though their membership is identical. Set notation ignores order; sequence notation retains it.

## Turn the list into a check on reasoning

If a count predicts six arrangements beginning with $A$, the first row verifies it. If it predicts twelve beginning with $A$ or $B$, the first two rows verify it. Small exhaustive lists are useful for learning which details matter before relying on formulas for much larger collections.

## Check your understanding

How many arrangements end in $D$? List them. If one of the $24$ arrangements is chosen uniformly, what is the probability that it ends in $D$?

<details markdown="1">
<summary>Work through the answer</summary>

Fix $D$ in the last position and arrange $A,B,C$ in the other three. There are $3!=6$ possibilities:

$$ABCD,\ ACBD,\ BACD,\ BCAD,\ CABD,\ CBAD.$$

With uniform selection from all $24$ arrangements, the probability is $6/24=1/4$. The counting result itself needs no random-selection assumption; the probability statement additionally uses uniform weights.
