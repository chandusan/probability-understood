# A combination remembers membership

A combination of size $k$ is a subset containing $k$ distinct objects. It answers “which objects?” and deliberately forgets the order in which they were chosen. To list combinations without duplicates, write their members in a consistent order.

## All triples from five objects

Start with $\{A,B,C,D,E\}$. There are ten subsets of size three:

| First five | Remaining five |
|---|---|
| $\{A,B,C\}$ | $\{A,D,E\}$ |
| $\{A,B,D\}$ | $\{B,C,D\}$ |
| $\{A,B,E\}$ | $\{B,C,E\}$ |
| $\{A,C,D\}$ | $\{B,D,E\}$ |
| $\{A,C,E\}$ | $\{C,D,E\}$ |

These are exactly the ten combinations shown in the slide. We have written each subset alphabetically only to make the list easy to check. Alphabetical order is a **standard way of describing a set**, not an extra selection requirement.

For instance, $\{C,A,B\}$ is the same subset as $\{A,B,C\}$; it is not an eleventh combination.

## A systematic list avoids omissions

Group the triples by their alphabetically first member. If the first member is $A$, choose the other two from $B,C,D,E$, producing six triples. If it is $B$, choose two from $C,D,E$, producing three. If it is $C$, only $D,E$ remain, producing one. No triple can start with $D$ or $E$ in this standardized description.

The disjoint cases give $6+3+1=10$. Every triple has exactly one first member, so the cases neither overlap nor miss anything.

## Selecting and leaving out are paired

Each selected triple leaves out a unique pair. Selecting $\{A,C,E\}$ is equivalent to leaving out $\{B,D\}$. Consequently,

$$
\binom53=\binom52=10.
$$

This is an example of a bijection: every choice on one side corresponds to exactly one choice on the other. It explains a useful symmetry without needing to manipulate factorials.

In the ordinary combination model, an object cannot appear twice: $\{A,A,B\}$ is not a size-three subset. Repeated category selections require a different model, introduced with stars and bars.

## Check your understanding

How many of these ten triples contain $A$? How many do not?

<details markdown="1"><summary>Reveal the partition</summary>

A triple containing $A$ needs two additional members from the other four, giving $\binom42=6$. A triple without $A$ consists of three members from the other four, giving $\binom43=4$.

These mutually exclusive cases exhaust the ten triples: $6+4=10$. This is also the idea behind Pascal's identity.

</details>
