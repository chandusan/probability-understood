# A factorial counts a complete ordering

To arrange $n$ distinct objects, fill the positions from left to right. Each choice removes one object from the pool, so the available counts fall from $n$ to $1$. Their product is the factorial $n!$.

## Fill every position exactly once

The first position has $n$ choices. Once it is filled, $n-1$ objects remain for the second. After $k-1$ positions have been filled, the $k$th position has

$$n-k+1$$

choices. The final position has one choice: the only unused object.

The product rule gives

$$\boxed{n!=n(n-1)(n-2)\cdots3\cdot2\cdot1.}$$

The exclamation mark is part of the notation; it denotes a product, not emphasis. For example, $5!=5\cdot4\cdot3\cdot2\cdot1=120$.

## Why this construction neither misses nor duplicates an ordering

Every arrangement determines a unique first object, second object, and so on, so there is one path of choices that builds it. Conversely, any path selecting each object once produces a valid arrangement. This one-to-one correspondence is the reason multiplying paths answers the arrangement question.

The objects must be distinguishable. Swapping two distinct books creates a new ordering, even if their subjects match. If some objects are truly identical, the raw factorial can count the same visible arrangement several times; a later rule will correct that repetition.

## Why zero factorial is one

There is exactly one way to arrange no objects: the empty arrangement. It contains no positions and requires no choices, but it is still one completed arrangement of the specified empty collection.

This differs from an impossible task that has zero valid arrangements. An empty shelf with no books has one arrangement; trying to place a required book that does not exist has no valid outcome.

Thus

$$\boxed{0!=1.}$$

<details markdown="1">
<summary>Connect the empty arrangement to the factorial recurrence</summary>

A nonempty arrangement can be formed by choosing its first object in $n$ ways, then arranging the remaining $n-1$ objects. Therefore

$$n!=n(n-1)!.$$

At $n=1$, there is exactly one arrangement of one object, so $1!=1\cdot0!$ requires $0!=1$. This matches the direct combinatorial interpretation rather than imposing an arbitrary exception.

It also matches the empty-product convention: a product of zero factors is the multiplicative identity one, so adding no choices to a completed construction leaves its count unchanged.

</details>

## Check your understanding

How many arrangements are there of five distinct books? How many if one specified book must be first? Why should the remaining count involve $4!$ rather than $5!$?

<details markdown="1">
<summary>Work through the answer</summary>

Without restrictions, there are $5!=120$ arrangements. Fixing the specified book in the first position leaves four distinct books to arrange freely, giving $1\cdot4!=24$. The first position contributes only one choice. We do not still have five free choices there, so using $5!$ would include arrangements that violate the restriction.

</details>
