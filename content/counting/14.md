# The product rule across many stages

A long sequence of choices is built by repeatedly extending partial outcomes. If every partial history at stage $i$ has exactly $n_i$ valid next choices, each new stage multiplies the number of histories by $n_i$.

## Build up the total

After the first stage there are $n_1$ partial outcomes. After the second, there are $n_1n_2$. After the third, there are $n_1n_2n_3$.

Continuing through $k$ stages gives

$$\boxed{N=n_1n_2\cdots n_k=\prod_{i=1}^{k}n_i.}$$

The counts can differ between stages. What must stay constant is the number of available choices **across all allowed histories reaching the same stage**.

## A small example with different stage sizes

A hypothetical code has one letter from $\{A,B,C\}$, then one digit from $\{0,1,2,3\}$, then one of two symbols. If every combination is allowed, its number of possibilities is

$$3\cdot4\cdot2=24.$$

Each final code has one unambiguous letter, digit, and symbol, so the sequence of choices describes it uniquely. No two different paths accidentally produce the same code.

## Restrictions can still fit the product rule

Arrange three different books from a set of five. The first stage has five choices, the second four, and the third three. The available titles depend on prior choices, but the counts are always $5,4,3$. Hence the number of ordered arrangements is $5\cdot4\cdot3=60$.

This is not probabilistic independence. Indeed, the rule “do not repeat a book” makes the allowed next choices depend on the previous choices. Counting multiplication survives because the number of continuations is consistent.

## When a single product is not enough

Suppose a travel plan has two first-leg options. One permits three second-leg connections and the other permits five. If each of those second-leg choices has two final connections, the count is

$$3\cdot2+5\cdot2=16.$$

We first count complete plans within each disjoint first-leg case, then add. Equivalently, there are $(3+5)\cdot2=16$ two-stage histories to extend. A useful count may combine both principles rather than use only one.

<details markdown="1">
<summary>Why the rule is valid for any number of stages</summary>

Suppose the number of partial histories after $i-1$ stages is $n_1\cdots n_{i-1}$. Each of those histories has exactly $n_i$ continuations. These continuation groups are disjoint as histories, because their preceding choices differ.

By the two-stage rule, the number after stage $i$ is $(n_1\cdots n_{i-1})n_i$. Starting with $n_1$ and repeating this argument establishes the formula for all $k$. A unique construction then identifies those histories with the desired final outcomes.

</details>

## Check your understanding

A three-stage process has two first choices, three second choices after either first choice, and two final choices after every second-stage history. How many outcomes? What changes if one second-stage history has one extra final choice?

<details markdown="1">
<summary>Work through the answer</summary>

The uniform tree has $2\cdot3\cdot2=12$ leaves. One extra final choice on exactly one history adds one leaf, giving $13$. Using a final-stage factor of three everywhere would incorrectly add an extra choice to all six second-stage histories, producing $18$ instead.

</details>
