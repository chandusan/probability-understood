# A probability model has three parts

A probability space specifies what can happen, which collections of outcomes count as measurable events, and how those events are weighted. The notation $(\Omega,\mathcal F,\mathbb P)$ packages those three decisions together.

## Read the three symbols

| Symbol | Name | Job |
|---|---|---|
| $\Omega$ | Sample space | All possible outcomes |
| $\mathcal F$ | Sigma-algebra of events | The collections of outcomes to which probabilities are assigned |
| $\mathbb P$ | Probability measure | A function $\mathbb P:\mathcal F\to[0,1]$ satisfying the probability axioms |

$S$ and $\Omega$ are alternative common symbols for a sample space; $P$ and $\mathbb P$ serve the same probability role. The important difference is between an individual outcome, a set of outcomes, and a function on such sets.

For one fair die, $\omega=4$ is an outcome. The event $E=\{2,4,6\}$ belongs to $\mathcal F$. The number $\mathbb P(E)=1/2$ is a probability.

## Why introduce an event collection?

In the finite counting examples, we can take $\mathcal F=\mathcal P(\Omega)$, the power set containing every subset of $\Omega$. There is no obstacle to assigning probabilities to all these subsets by adding outcome weights.

For uncountable spaces such as real-valued positions, assigning a consistent length-based probability to every imaginable subset becomes problematic. The event collection specifies the subsets on which the measure is defined. This is a mathematical property of a set in the model; it does not mean an event must be directly detectable by a physical instrument.

The slide's phrase “strictly measurable events” can therefore be read simply as **measurable events**. There is no separate extra meaning of “strictly” needed here.

## Closure keeps ordinary questions available

A sigma-algebra contains $\Omega$, is closed under taking complements, and is closed under countable unions. Thus if events are allowed, “not this event” and “at least one of these events” remain allowed. Countable intersections are then included by De Morgan's laws.

We will not need to construct unusual continuous event collections to count dice, cards, or arrangements. But this framework explains what the probability axioms are acting on.

## Check your understanding

For $\Omega=\{H,T\}$, write the complete power set. Which object is an outcome, which is an event, and which is a probability: $H$, $\{H\}$, and $1/2$?

<details markdown="1">
<summary>Work through the answer</summary>

The power set is

$$\mathcal P(\Omega)=\{\varnothing,\{H\},\{T\},\{H,T\}\}.$$

$H$ is an individual outcome; $\{H\}$ is the singleton event that the outcome is heads; $1/2$ is the weight that a fair-coin model assigns to that event. We often write $P(H)$ informally, but the precise event notation is $P(\{H\})$.
