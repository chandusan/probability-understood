# Normalize a power-shaped density before using it

Suppose $X$ has density $f(x)=cx^n$ for $0<x<1$, and $f(x)=0$ elsewhere. Find the constant $c$, then find $P(X>0.05)$. The exponent $n$ is a fixed parameter of the model; the question does not give it a numerical value.

## First check which values of the parameter are possible

A density must have finite total area. The integral $\int_0^1x^n\,dx$ is finite exactly when $n>-1$. If the intended $n$ is a nonnegative integer, this condition is automatically satisfied.

We will solve the problem for **any real $n>-1$**. The symbol $c$ adjusts the vertical scale so that the total area becomes one.

## Part (a): turn the shape into a probability density

The only nonzero part lies between zero and one, so normalization requires

$$\int_0^1cx^n\,dx=1.$$

The factor $c$ does not change with $x$, so it comes outside the integral. For $n>-1$, an antiderivative of $x^n$ is $x^{n+1}/(n+1)$:

$$c\int_0^1x^n\,dx
=c\left[\frac{x^{n+1}}{n+1}\right]_0^1
=c\left(\frac1{n+1}-0\right)
=\frac{c}{n+1}.$$

Set this equal to one and multiply both sides by $n+1$:

$$\boxed{c=n+1.}$$

For example, $n=0$ gives the uniform density $1$; $n=1$ gives the triangular density $2x$. The normalization constant changes because the area under the unscaled shape changes.

## Part (b): identify the requested region before calculating

The event $X>0.05$ selects the region from $0.05$ to $1$. There is no probability outside the support. Thus

$$\begin{aligned}
P(X>0.05)
&=\int_{0.05}^1(n+1)x^n\,dx\\
&=\left[x^{n+1}\right]_{0.05}^1\\
&=\boxed{1-(0.05)^{n+1}}.
\end{aligned}$$

The answer depends on $n$, so a single decimal answer would be unjustified without specifying it.

## Use the complement as a second route

The probability excluded by the question is $P(X\le0.05)$. Its area is

$$\int_0^{0.05}(n+1)x^n\,dx=(0.05)^{n+1}.$$

Subtracting this small left-hand region from the full area gives the same answer. This also makes the intuition visible: for a positive $n$, the density puts more weight near one, so very little probability sits below $0.05$.

| Parameter | Density on $(0,1)$ | $P(X>0.05)$ |
|---|---|---|
| $n=0$ | $1$ | $0.95$ |
| $n=1$ | $2x$ | $0.9975$ |
| $n=2$ | $3x^2$ | $0.999875$ |

These are three different distributions, not three answers to the same numerically specified problem.
