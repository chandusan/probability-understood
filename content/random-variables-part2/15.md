# Find the probability of one fixed category arrangement

Roll a fair die five times independently, with $X$ counting sixes and $Y$ counting fives. Write $F$ for any face in $\{1,2,3,4\}$. Before counting all arrangements with particular totals, consider the specific pattern $F5FF6$.

## Translate every symbol into a requirement

The pattern $F5FF6$ means:

| Roll | Required category | Probability |
|---|---|---:|
| 1 | Any of 1, 2, 3, 4 | $4/6$ |
| 2 | Five | $1/6$ |
| 3 | Any of 1, 2, 3, 4 | $4/6$ |
| 4 | Any of 1, 2, 3, 4 | $4/6$ |
| 5 | Six | $1/6$ |

The requirements concern different independent rolls, so we multiply their probabilities:

$$
\begin{aligned}
P(F5FF6)
&=\frac46\frac16\frac46\frac46\frac16\\
&=\left(\frac16\right)^1
\left(\frac16\right)^1
\left(\frac46\right)^3\\
&=\frac{64}{7776}.
\end{aligned}
$$

Each $F$ may be a different face. For example, $15236$ fits, and so does $45446$. The pattern fixes the categories at each position, not the actual faces in the $F$ positions.

## Check the same probability by elementary counting

There are four choices for each of the three $F$ positions, and only one choice for each fixed 5 or 6. Hence $F5FF6$ represents

$$4^3=64$$

actual die sequences. Each has probability $1/7776$, giving the same $64/7776$.

This distinction matters: the slide's category “sequence” stands for several elementary outcomes. A specific actual sequence such as $15236$ has probability $1/7776$; the whole pattern $F5FF6$ has probability $64/7776$.

## Generalize to arbitrary counts

Any one fixed arrangement containing $x$ sixes, $y$ fives, and $5-x-y$ symbols $F$ has probability

$$
\boxed{
\left(\frac16\right)^x
\left(\frac16\right)^y
\left(\frac46\right)^{5-x-y}.
}
$$

Rearranging those categories does not change this product. For example, $65FFF$ and $F5FF6$ both have one six, one five, and three $F$ positions, so they have equal probability.

However, arrangements with different counts need not be equally likely. The all-$F$ pattern has probability $(4/6)^5$, whereas the all-six pattern has probability $(1/6)^5$.

## One arrangement is not the entire joint event

The event $X=1,Y=1$ includes every possible placement of the single six and single five, not only $F5FF6$. There are five choices for the six's position and then four remaining choices for the five's position:

$$5\cdot4=20.$$

These category patterns are disjoint and each has probability $64/7776$, so

$$P(X=1,Y=1)=20\frac{64}{7776}=\frac{1280}{7776}.$$

The general position count is the remaining ingredient in the joint PMF.
