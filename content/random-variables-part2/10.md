# Set up the image-audit problem before counting

A dataset contains 25 distinct images: 12 perfectly labeled, 8 with minor bounding-box errors, and 5 completely mislabeled. Select 7 images uniformly without replacement. Let $X$ count images with minor errors and $Y$ count completely mislabeled images in the sample. We want $p(x,y)=P(X=x,Y=y)$.

## State precisely what “randomly draws” means

We use a simple random sample: every set of 7 distinct images has the same chance of selection. One way to generate it is to draw one image uniformly from the remaining images at each of seven steps.

Every ordered sequence of seven distinct images then has probability

$$
\frac1{25}\frac1{24}\frac1{23}\frac1{22}\frac1{21}\frac1{20}\frac1{19}.
$$

Each particular set of seven images can appear in $7!$ orders. Since every set has the same number of equally likely orders, all sets have equal probability. Therefore the denominator for an unordered count is

$$
\binom{25}{7}=480700.
$$

We use sets because the question asks how many of each category are selected, not which category appears first.

## Translate the requested pair into a full sample composition

If $X=x$ and $Y=y$, then the sample contains

| Category | Images available | Images required in the sample |
|---|---:|---:|
| Minor errors | 8 | $x$ |
| Completely mislabeled | 5 | $y$ |
| Perfect | 12 | $7-x-y$ |

The last count is forced because all three categories must total seven. For example, $(X,Y)=(2,1)$ means **2 minor-error images, 1 completely mislabeled image, and 4 perfect images**.

## Identify which pairs are possible

Both counts must be nonnegative integers. The sample holds only seven images, the dataset has only five completely mislabeled images, and the perfect-image count cannot be negative. Hence

$$
\boxed{x\in\{0,\ldots,7\},\quad y\in\{0,\ldots,5\},\quad x+y\le7.}
$$

The additional capacity condition $7-x-y\le12$ is automatically satisfied here, because the sample itself has only seven images.

For instance, $(7,0)$ is possible, $(2,5)$ is possible, $(3,5)$ is impossible because it requires eight sampled images, and $(0,6)$ is impossible because only five completely mislabeled images exist.

## The counting plan

For each allowed pair, choose the required images from each category. Then divide by the number of all possible samples:

$$
\boxed{
p(x,y)=\frac{\binom8x\binom5y\binom{12}{7-x-y}}{\binom{25}{7}}.
}
$$

The next step is to justify each numerator factor and why multiplying those counts includes every qualifying sample exactly once. A formula is useful only after its choices and its support are clear.
