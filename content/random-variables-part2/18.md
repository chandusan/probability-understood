# Build the dice table from exact sequence counts

In five independent fair-die rolls, $X$ is the number of sixes and $Y$ the number of fives. The joint PMF table places the probability of every possible pair in one cell. Using exact favorable counts makes the table easier to check and avoids errors from adding rounded decimals.

## Read the row and column variables explicitly

For the dice table, take **rows to be $X$ and columns to be $Y$**. This matches the shaded $X>Y$ region shown later in the source. The audit table used the opposite orientation, so always check the labels.

There are $6^5=7776$ equally likely actual face sequences. The following table gives their counts; **divide every entry by 7776 to get $p(x,y)$**.

| $X\backslash Y$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---:|---:|---:|---:|---:|---:|
| $0$ | 1024 | 1280 | 640 | 160 | 20 | 1 |
| $1$ | 1280 | 1280 | 480 | 80 | 5 | 0 |
| $2$ | 640 | 480 | 120 | 10 | 0 | 0 |
| $3$ | 160 | 80 | 10 | 0 | 0 | 0 |
| $4$ | 20 | 5 | 0 | 0 | 0 | 0 |
| $5$ | 1 | 0 | 0 | 0 | 0 | 0 |

For example, the row $X=2$, column $Y=1$ entry gives

$$p(2,1)=\frac{480}{7776}\approx0.0617,$$

which matches the rounded source table.

## Explain three revealing cells

For $(0,0)$, all rolls must be from 1 through 4. There are $4^5=1024$ sequences:

$$p(0,0)=\frac{1024}{7776}=\left(\frac46\right)^5.$$

For $(5,0)$, only the sequence $66666$ qualifies:

$$p(5,0)=\frac1{7776}.$$

For $(3,2)$, all rolls are sixes or fives, with no remaining category. Choose the three six positions and fill the others with fives:

$$p(3,2)=\frac{\binom53}{7776}=\frac{10}{7776}.$$

Every cell with $x+y>5$ is exactly zero. These are impossible combinations, unlike the small but positive entry $p(5,0)$.

## Why the table mirrors across its diagonal

Swapping every 5 and 6 in an actual sequence changes the counts from $(x,y)$ to $(y,x)$. This swap is reversible, and all actual sequences have equal probability. Therefore the two cells contain the same number of outcomes:

$$p(x,y)=p(y,x).$$

For example, $(2,1)$ and $(1,2)$ both have count 480. The table's visual symmetry follows from a concrete operation on the underlying outcomes.

## Add cells for a combined count

The event “exactly two rolls are either five or six” is $X+Y=2$. Its pairs are $(0,2)$, $(1,1)$, and $(2,0)$, so

$$
P(X+Y=2)=\frac{640+1280+640}{7776}=\frac{2560}{7776}.
$$

A direct count confirms it: choose the two special positions in $\binom52$ ways; each special position has two choices, 5 or 6; and each remaining position has four choices. Thus

$$\binom52\,2^2\,4^3=10\cdot4\cdot64=2560.$$

The table organizes the same elementary outcomes by how many of the two special rolls are sixes and how many are fives.
