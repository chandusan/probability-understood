# Find the probability of more sixes than fives

Roll a fair die five times independently. Let $X$ count sixes and $Y$ count fives. The question is $P(X>Y)$: add the probabilities of all possible count pairs with strictly more sixes than fives. Ties do not qualify.

## Select pairs satisfying both conditions

A qualifying pair must satisfy

$$x>y\quad\text{and}\quad x+y\le5,$$

with $x,y$ nonnegative integers. The first condition is the event we want; the second comes from the five-roll sample size.

List the possibilities systematically by fixing $x$:

| Number of sixes $x$ | Allowed numbers of fives $y$ | Qualifying pairs |
|---:|---|---|
| 0 | None | None |
| 1 | 0 | $(1,0)$ |
| 2 | 0, 1 | $(2,0),(2,1)$ |
| 3 | 0, 1, 2 | $(3,0),(3,1),(3,2)$ |
| 4 | 0, 1 | $(4,0),(4,1)$ |
| 5 | 0 | $(5,0)$ |

For example, $(4,2)$ satisfies $x>y$ but violates $x+y\le5$, so it contributes nothing. There are nine possible qualifying pairs.

## Add their probabilities, not the number of pairs

The 21 possible pairs are not equally likely. Counting nine favorable pairs and dividing by 21 would therefore be invalid. Instead, count the equally likely actual die sequences inside each pair.

For any allowed pair,

$$
N(x,y)=\frac{5!}{x!y!(5-x-y)!}\,4^{5-x-y}
$$

is the number of actual sequences. The exact counts for our event are

| Sixes $x$ | Favorable sequence counts over allowed $y$ | Row total |
|---:|---|---:|
| 1 | $N(1,0)=1280$ | 1280 |
| 2 | $N(2,0)=640$, $N(2,1)=480$ | 1120 |
| 3 | $N(3,0)=160$, $N(3,1)=80$, $N(3,2)=10$ | 250 |
| 4 | $N(4,0)=20$, $N(4,1)=5$ | 25 |
| 5 | $N(5,0)=1$ | 1 |

These sets of sequences are disjoint because one sequence has only one pair of counts. Add their sizes:

$$1280+1120+250+25+1=2676.$$

## Divide by all possible sequences

There are $6^5=7776$ equally likely actual sequences, so

$$
\boxed{
P(X>Y)=\frac{2676}{7776}=\frac{223}{648}\approx0.34413580.
}
$$

The probability is approximately **34.41%**, agreeing with the source's rounded answer $0.3441$.

In PMF notation, the explicit sum we have evaluated is

$$
\begin{aligned}
P(X>Y)={}&p(1,0)\\
&+p(2,0)+p(2,1)\\
&+p(3,0)+p(3,1)+p(3,2)\\
&+p(4,0)+p(4,1)\\
&+p(5,0).
\end{aligned}
$$

## Why the answer is smaller than one half

Neither face is favored, so “more sixes” and “more fives” have the same probability. But those two events do not exhaust the outcomes: equal counts are possible, including zero of each. The next explanation uses that symmetry to obtain the same answer by counting only ties.
