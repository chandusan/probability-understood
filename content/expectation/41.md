# A moment-generating function packages many averages together

A moment-generating function, or MGF, is $M_X(t)=E(e^{tX})$. At first this may look like an unusual transformed expectation. Its purpose is practical: differentiating it with respect to $t$ and then setting $t=0$ reveals the moments $E(X),E(X^2),E(X^3)$, and so on.

## Keep the roles of $X$ and $t$ separate

$X$ is the random observation. The number $t$ is a freely chosen input to a function. For each fixed $t$, transform every possible value $x$ into $e^{tx}$ and average those transformed values.

For example, if $P(X=0)=P(X=1)=1/2$, then

$$M_X(t)=\frac12e^{t\cdot0}+\frac12e^{t\cdot1}
=\frac{1+e^t}{2}.$$

This function is not a PMF or density; it does not assign probabilities to values of $t$. It is a way to summarize the original distribution.

## Why the exponential generates powers

Holding a possible value $x$ fixed while differentiating in $t$ gives

$$
\frac{d}{dt}e^{tx}=xe^{tx},\qquad
\frac{d^2}{dt^2}e^{tx}=x^2e^{tx}.
$$

Each derivative brings down another factor $x$. At $t=0$, the exponential factor becomes $e^0=1$, leaving $x$ or $x^2$. Averaging then produces the corresponding moment.

For the two-value example,

$$M_X'(t)=\frac{e^t}{2},\qquad M_X''(t)=\frac{e^t}{2},$$

so $E(X)=M_X'(0)=1/2$ and $E(X^2)=M_X''(0)=1/2$.

## The condition behind these operations

To use the usual MGF theory, require $M_X(t)$ to be finite throughout some open interval containing zero. This supports differentiating under the expectation and guarantees the moments generated in this way.

Every bounded random variable in our binomial and uniform examples has such an MGF. An unbounded variable may not. All distributions satisfy $E(e^{0X})=1$, but finiteness at the single point $t=0$ is not enough for a useful MGF around zero.
