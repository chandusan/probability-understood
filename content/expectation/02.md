# Why expectation is a weighted sum or integral

For a discrete random variable, expectation adds each possible value multiplied by its probability. For a continuous random variable with a density, small probability-weighted contributions become an integral. Both calculations express the same idea: average values according to how frequently they occur in the model.

## The discrete definition

If $p(x)=P(X=x)$, then

$$
\boxed{E(X)=\sum_x x\,p(x).}
$$

The sum runs over possible values of $X$, not over all underlying outcomes separately. All outcomes that produce the same value have already been collected into $p(x)$.

For a fair die,

$$
E(X)=1\frac16+2\frac16+\cdots+6\frac16=\frac{21}{6}=3.5.
$$

Probabilities supply the weights, and their sum is $1$. Negative values contribute negatively; unlikely large values can still make substantial contributions.

## Where the continuous integral comes from

Partition the possible values into very narrow intervals. A small interval near $x$ with width $\Delta x$ has probability approximately $f(x)\Delta x$. Its contribution to the average is therefore approximately

$$
\underbrace{x}_{\text{value}}\;
\underbrace{f(x)\Delta x}_{\text{probability near that value}}.
$$

Adding these contributions and shrinking the intervals gives

$$
\boxed{E(X)=\int_{-\infty}^{\infty}x f(x)\,dx.}
$$

When $f$ is zero outside $(a,b)$, the same integral can be written with bounds $a,b$. The factor $f(x)$ alone is a density height, not a point probability. The integration accounts for interval width.

## Do not confuse three integrals

| Calculation | What it measures |
|---|---|
| $\int f(x)\,dx$ over the full support | Total probability, which must be $1$ |
| $\int_{-\infty}^a f(x)\,dx$ | The probability $P(X\le a)$ |
| $\int x f(x)\,dx$ over the full support | The weighted average value $E(X)$ |

A finite expectation is guaranteed when $E(|X|)<\infty$. Bounded variables in our first examples satisfy this automatically. For unbounded variables, convergence must be checked: not every distribution has a finite mean.
