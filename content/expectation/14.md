# Average the quantity you actually care about

Often the random variable we observe is not the quantity we want to average. We observe outages $X$ but care about a cost $C(X)$, or observe a waiting time $X$ but care about its reciprocal. A function of a random variable is another random variable, and its expectation weights its own values by the probabilities that produce them.

## Transform each possible value before averaging

Suppose $X$ is equally likely to be $1$ or $3$. If the quantity of interest is $Y=X^2$, then $Y$ is equally likely to be $1$ or $9$. Consequently,

$$
E(Y)=E(X^2)=\frac12(1)+\frac12(9)=5.
$$

But

$$
[E(X)]^2=\left[\frac12(1)+\frac12(3)\right]^2=2^2=4.
$$

The first calculation squares each possible observation and averages the results. The second averages the original observations and then squares that single number. Different orders of operations generally give different answers.

## Why the probabilities stay attached to the original outcomes

If the event $X=3$ has probability $1/2$, the same event makes $X^2=9$. Squaring the value does not square the event's probability. We change the value contributed by that outcome, leaving its probability weight unchanged.

More generally,

$$\boxed{E[g(X)]=\sum_x g(x)p(x)}$$

for a discrete variable, and

$$\boxed{E[g(X)]=\int g(x)f(x)\,dx}$$

for a variable with a density, whenever the expectation is well defined.

## There is no need to find a new distribution first

One method would list all possible values of $Y=g(X)$, combine any values produced in several ways, and then compute $E(Y)$. The formulas above do that grouping implicitly. They are especially useful when $g$ is many-to-one or the transformed density would be awkward to derive.

<details markdown="1"><summary>When may we move the function outside expectation?</summary>

For an affine function $g(x)=ax+b$, we have $E[g(X)]=aE(X)+b=g(E(X))$. Nonlinear functions such as squares, reciprocals, and exponentials do not have this property in general. The squared example above supplies a concrete counterexample.

</details>
