# Two sample spaces, one tiny probability

The poem problem can be solved using visible letter strings or individually labeled tiles. Both approaches give the same probability when the favorable count and the total count describe the same kind of outcome. Comparing them explains why repeated-letter factorials belong in the answer.

## Count visible strings

Write $n_L$ for the number of tiles carrying letter $L$, and let

$$D=\prod_{L=A}^{Z}n_L!
=(4!)^2(2!)^6(3!)^3(5!)^2\,7!\,8!.$$

The number of visible strings is $59!/D$. Exactly one string matches the specified target, so

$$\boxed{P(\text{target})=\frac{1}{59!/D}=\frac D{59!}.}$$

Using the inventory gives

$$P(\text{target})\approx1.6801426698\times10^{-61}.$$

The slide rounds this to about $1.7\times10^{-61}$. The number of possible visible strings is approximately $5.9518755043\times10^{60}$, and the probability is its reciprocal.

## Why the visible strings are equally likely

Imagine writing a tiny unique serial number on every physical tile. There are $59!$ equally likely orders of these numbered tiles under the uniform shuffle assumption.

Fix any visible string using the correct inventory. Its four A-positions can receive the four numbered A-tiles in $4!$ ways. Its eight S-positions can receive the eight numbered S-tiles in $8!$ ways, and similarly for every other letter. Therefore it has exactly $D$ numbered versions.

This multiplicity is the same for every visible string. Each visible string consequently receives probability $D/59!$. That establishes the equal-likelihood claim instead of merely assuming it after erasing labels.

## Solve again with labeled tiles

In the labeled sample space, the total is $59!$ and the number of favorable outcomes is $D$, because any interchange of identical-looking tiles leaves the target text unchanged. Thus

$$\frac{\text{favorable labeled orders}}{\text{all labeled orders}}
=\frac D{59!}.$$

The tempting answer $1/59!$ uses one favorable **visible string** but counts all **labeled orders** in the denominator. That mismatch makes the event seem even rarer than it is.

## The same answer appears by drawing letters sequentially

The target begins S, H, E. The probabilities of matching those positions in sequence are $8/59$, then $3/58$, then $7/57$, conditional on having matched the previous positions.

Continue through the whole target. Every appearance of S uses one of the remaining S-tiles, producing numerator factors $8\cdot7\cdots1=8!$. Every other letter likewise contributes its factorial. The denominator is $59\cdot58\cdots1=59!$, so the product again becomes $D/59!$.

These draws are dependent: using a letter changes the inventory. Conditional probabilities account for that dependence correctly.

## Very small does not mean impossible

The event is possible because the inventory matches. Its probability is positive, although a direct simulation is extraordinarily unlikely to show a success. Observing zero successes in a feasible number of trials would not establish that the theoretical probability is zero.

For large factorials, calculations can use logarithms:

$$\log P=\sum_L\log(n_L!)-\log(59!).$$

This avoids first constructing huge floating-point factorials. Exact integer arithmetic also works for this particular example.
