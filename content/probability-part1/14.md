# Build a sample space by combining choices

When an outcome contains several components, the sample space is built from all allowed combinations of those components. The multiplication principle counts those combinations; a probability model then tells us how likely they are.

## Two dice as a Cartesian product

For labeled dice,

$$S=\{(i,j):i,j\in\{1,2,3,4,5,6\}\}.$$

This is a Cartesian product of two six-element sets, so it contains $36$ ordered pairs. The slide uses $S$ and $\Omega$ for the sample space; both are common symbols for the same role.

The product construction counts outcomes without requiring independence. Independence is needed for a product probability such as $P(i,j)=P(i)P(j)$, not for forming a set of candidate combinations. If a physical constraint rules out some combinations, the actual space must reflect that constraint.

## Solve the grid-search prompt

The slide gives three tuning choices:

| Parameter | Allowed values |
|---|---|
| Number of estimators | $\{100,200,300,400\}$ |
| Maximum depth | $\{10,20,30\}$ |
| Criterion | $\{\text{gini},\text{entropy}\}$ |

The space of configurations is

$$S=\{100,200,300,400\}\times\{10,20,30\}\times\{\text{gini},\text{entropy}\}.$$

A typical element is $(200,20,\text{entropy})$. There are

$$|S|=4\times3\times2=24$$

configurations. For each estimator choice, pair every depth; for each of those pairs, choose either criterion.

## Configurations are not necessarily random outcomes

An exhaustive grid search deliberately visits every configuration. It is not automatically a random experiment. We can view this finite set as a sample space if, for example, we randomly choose one configuration. Uniform random selection would assign each probability $1/24$.

Also, $24$ configurations do not imply $24$ distinct fitted models or scores. Two configurations might yield identical results. If training uses a random seed, the complete experiment may need to include that seed or the random training result in its outcome description. The source's phrase “24 distinct training outcomes” is most precise when understood as $24$ distinct parameter configurations.

## Check your understanding

If a fourth parameter has two permitted values, how many unconstrained configurations are there? Does each necessarily have probability $1/48$?

<summary>Work through the answer</summary>

There are $4\cdot3\cdot2\cdot2=48$ combinations. Equal probability follows only if the selection mechanism is uniform over those combinations. An exhaustive search has no random choice among configurations unless we introduce one; a biased random search can assign different weights.
