# An event is a collection of outcomes

An experiment produces one outcome. An event collects all the outcomes that would make a particular statement true. This turns a question such as “Did we roll an even number?” into something we can describe precisely.

## Separate the world from the question

For one ordinary die roll, the sample space is

$$
S=\{1,2,3,4,5,6\}.
$$

Define the event “an even number appears” as

$$
E=\{2,4,6\}.
$$

The experiment does not produce the whole set $E$. It produces one outcome, perhaps 4. Because $4\in E$, we say **event $E$ occurred**. If the result were 5, it would not have occurred.

In general,

$$
E\subseteq S,
\qquad
E\text{ occurs precisely when the observed outcome belongs to }E.
$$

The picture above uses the large rectangle for $S$ and the shaded region for $E$. The shape is a membership diagram, not yet a probability calculation. A region taking up half a drawing need not have probability one half.

## Different questions select different subsets

For the same die experiment, we could define:

| Question | Event |
|---|---|
| Did we roll a number above 4? | $\{5,6\}$ |
| Did we roll exactly 3? | $\{3\}$ |
| Did we roll a possible face? | $S$ |
| Did we roll 9? | $\varnothing$ |

An event may contain one outcome, several outcomes, all outcomes, or none. It remains a set in every case. Notice that the outcome 3 and the singleton event $\{3\}$ play different roles.

We have specified what counts as success before assigning its probability. Fairness is unnecessary for deciding whether 4 is even; it matters when calculating how likely an even result is.

## A small qualification for continuous models

For our finite examples, every subset can be an event. In general probability theory, events belong to a chosen collection of **measurable sets**, usually denoted $\mathcal F$. Continuous models require this qualification because some pathological subsets cannot be assigned probabilities consistently in the usual model. Intervals, rectangles, and the geometric regions used here are measurable; no pathology is involved in these examples.

## Check your understanding

For $S=\{1,2,3,4,5,6\}$, define $H$ as “the result is at least 4.” List $H$. If the observed outcome is 4, what occurred: one outcome, the event, or both descriptions?

<details markdown="1"><summary>Reveal the reasoning</summary>

$H=\{4,5,6\}$. The experiment produced the single outcome 4. Since that outcome belongs to $H$, the statement “event $H$ occurred” is also true. These describe the same trial at different levels: its exact outcome and a property that outcome satisfies.

</details>
