# Membership connects an outcome to an event

The symbol $\in$ asks a very specific question: does this object appear inside this set? It does not mean that the object equals the set, and it does not compare one set's contents with another's.

## Read the symbols as sentences

If $A=\{2,4,6\}$, then

$$
4\in A
$$

means “4 belongs to $A$.” Conversely,

$$
5\notin A
$$

means “5 does not belong to $A$.” The letter $e$ often stands for an arbitrary elementary outcome, so $e\in A$ says that outcome $e$ makes event $A$ occur.

The set on the right can be a sample space, an event, or some other collection. In the die example, $4\in A$ and $4\in S$ are both true because $A\subseteq S$.

## Do not confuse membership and containment

| Statement | What is being compared? | Meaning |
|---|---|---|
| $4\in A$ | An outcome and a set | 4 is a member of $A$ |
| $\{4\}\subseteq A$ | Two sets | Every member of $\{4\}$ is in $A$ |
| $A\subseteq S$ | Two sets | Every outcome in $A$ is possible in $S$ |

Here, $\{4\}\in A$ is false: the listed members of $A$ are the numbers 2, 4, and 6, not a set containing 4. In other mathematical settings sets can themselves be elements, but that is not how this particular event was defined.

The braces matter because they distinguish the number 4 from the set whose only element is 4.

## A data-science reading of the same idea

Suppose a feature records a customer's membership tier, and define

$$
C_{\text{paid}}=\{\text{silver},\text{gold},\text{platinum}\}.
$$

For a feature value $x_i=\text{gold}$, the statement $x_i\in C_{\text{paid}}$ is true. For $x_i=\text{free}$, it is false. Membership therefore expresses a filter or a categorical assignment with the same precision it gives an event.

A notation such as $C_k$ labels a particular category set; the subscript is a label, not multiplication. Always check what the elements are meant to be—feature values, records, outcomes, or something else.

Membership is not limited to discrete outcomes. In a continuous model, $0.4\in(0,1)$ is an equally valid statement.

## Check your understanding

For $A=\{1,3,5\}$, which statements are true: $3\in A$, $\{3\}\subseteq A$, $2\notin A$, and $\{3\}\in A$?

<details markdown="1"><summary>Reveal the answer</summary>

The first three are true. The last is false because the members of this $A$ are numbers, not singleton sets. Both $3\in A$ and $\{3\}\subseteq A$ capture the presence of 3, but their left-hand objects have different types.

</details>
