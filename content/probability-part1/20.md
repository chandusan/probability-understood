# Three cars: build outcomes before events

To decide which outcomes satisfy a condition, first describe one complete outcome. Here we record each car's turn in order. That keeps “the first car turns right” distinct from “the last car turns right.”

## Give each position a job

Write an outcome as three letters:

$$
(\text{first car},\ \text{second car},\ \text{third car}).
$$

Each position is either $L$ or $R$. The eight possible strings are

$$
S=\{LLL,LLR,LRL,LRR,RLL,RLR,RRL,RRR\}.
$$

The count is $2\times2\times2=8$: choose the first turn, then the second, then the third. This describes possible strings. It does not yet say that all eight have equal probabilities.

## Filter for exactly one right turn

The event $A$ requires exactly one $R$:

$$
A=\{LLR,LRL,RLL\}.
$$

One way to find these is to ask which of the three positions holds the $R$. Every other position must then be $L$.

“Exactly one” excludes both zero right turns and two or three right turns. Words such as *exactly*, *at least*, and *at most* change the event, so they deserve careful attention.

## Filter for all turns being the same

The event $C$ allows either all left or all right:

$$
C=\{LLL,RRR\}.
$$

Check the full list against both questions:

| Outcome | Exactly one $R$: in $A$? | All the same: in $C$? |
|---|---|---|
| $LLL$ | No | Yes |
| $LLR$ | Yes | No |
| $LRL$ | Yes | No |
| $LRR$ | No | No |
| $RLL$ | Yes | No |
| $RLR$ | No | No |
| $RRL$ | No | No |
| $RRR$ | No | Yes |

No outcome belongs to both events. Some belong to neither. We will soon call events with no shared outcomes **disjoint**.

## When can we turn these counts into probabilities?

If each car independently chooses left or right with probability $1/2$, then each complete string has probability $1/8$. Under that additional model,

$$
P(A)=\frac38,\qquad P(C)=\frac28=\frac14.
$$

Knowing only that each car has two possible directions does not justify those probabilities. Real traffic might favor one direction, and one driver's choice might be related to another's.

## Check your understanding

List the event “at least two cars turn right.” How is it different from “exactly two turn right”?

<details markdown="1"><summary>Reveal the event sets</summary>

“At least two” is $\{LRR,RLR,RRL,RRR\}$. “Exactly two” is $\{LRR,RLR,RRL\}$. The outcome $RRR$ belongs only to the first event because three is at least two but is not exactly two.
