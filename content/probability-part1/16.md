# Coordinates describe the experiment

The slide identifies a needle placement by its midpoint $(x,y)$ and orientation $\theta$. This gives a continuous sample space: each coordinate can vary through an interval of real values.

## Read the proposed space

The source writes

$$S=\{(x,y,\theta):-\infty<x<\infty,\ 0<y<d,\ 0\le\theta\le2\pi\}.$$

Here $x$ is the horizontal midpoint coordinate, $y$ is its vertical position inside one strip, and $\theta$ is measured from a horizontal ruled line. The picture's coordinates describe the needle's center, not one endpoint.

The restriction to one strip uses the repeating pattern of lines. Any vertical placement can be shifted by an integer multiple of $d$ into a representative strip without changing whether some line is crossed.

## Several coordinate labels can describe the same physical placement

An unlabeled needle has no arrowhead. Rotating it by $\pi$ swaps its endpoints but leaves the physical segment unchanged. Thus angles $\theta$ and $\theta+\pi$ represent the same placement, and $0$ and $2\pi$ duplicate a direction too.

The source's coordinates are therefore redundant if the goal is one unique label per unlabeled placement. A nonredundant representative can use $0\le\theta<\pi$. Using redundant coordinates is possible, but the probability model must handle their interpretation consistently.

Similarly, a full set of possible placements includes centers exactly on a ruled line. The source excludes $y=0,d$. Under continuous uniform placement those boundaries have probability zero, so their inclusion does not change crossing probabilities; it does matter if we claim to list literally every possible placement.

## A sample space does not provide a distribution

There is no proper uniform probability distribution over the entire real horizontal axis. We cannot simply say every real-valued $x$ is uniformly likely.

Fortunately, horizontal position is irrelevant to crossing an infinite family of horizontal lines. We can omit it, or restrict a representative horizontal interval without changing the crossing calculation. For the relevant coordinates, use a uniform vertical position within one strip and an independent uniform angle.

On the next page, $x$ is reused for a different quantity: distance to the nearest line. Keep this change of notation in mind. The horizontal coordinate on this page and the perpendicular distance on the next page are not the same measurement.

## Check your understanding

If an unlabeled needle lies at $30^\circ$, does $210^\circ$ describe a different physical segment with the same center? Why might $150^\circ$ still be grouped with $30^\circ$ for the crossing question?

<details markdown="1">
<summary>Work through the answer</summary>

$210^\circ=30^\circ+180^\circ$ reverses the direction along the same segment, so it is the same unlabeled placement. A $150^\circ$ needle is a reflected placement rather than the same segment, but it has the same vertical reach because $\sin150^\circ=\sin30^\circ$. At the same midpoint, both give the same crossing answer. The first equivalence removes endpoint direction; the second removes a distinction irrelevant to this particular event.
