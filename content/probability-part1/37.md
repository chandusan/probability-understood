# An intersection requires every membership test

An intersection is stricter than a union. An outcome stays only if **every** event in the collection contains it. With infinitely many events, passing the first hundred or the first million tests is not enough: the requirement must hold for every index.

## Repair the notation before reading it

The source slide has a font problem: a symbol that looks like “L” is meant to be an ellipsis, $\cdots$, and the large symbol that resembles “I” is an intersection sign, $\bigcap$. There is no additional event called L.

The finite formula should read

$$
\bigcap_{i=1}^{k}E_i
=E_1\cap E_2\cap E_3\cap\cdots\cap E_k.
$$

The countable formula is

$$
\bigcap_{i=1}^{\infty}E_i
=E_1\cap E_2\cap E_3\cap\cdots.
$$

In the three-circle picture, only the central region belonging to **all three** circles is shaded. A region in exactly two circles does not qualify.

## “For every” is the membership rule

$$
x\in\bigcap_{i=1}^{\infty}E_i
\quad\Longleftrightarrow\quad
x\in E_i\text{ for every positive integer }i.
$$

The symbol $\forall$ abbreviates “for every.” Compare it with the union's $\exists$, meaning “there exists.” To establish intersection membership, every test must pass. To disprove it, finding **one** failed test is enough.

For $E_1=\{1,2,3,4\}$, $E_2=\{2,3,4,5\}$, and $E_3=\{3,4,5,6\}$, the intersection is $\{3,4\}$. The outcome 2 survives the first two sets, but the third removes it.

## Infinitely shrinking intervals: one endpoint changes everything

Let $F_i=(0,1/i)$ on $S=\mathbb R$. Every individual interval is nonempty, and every finite intersection is nonempty:

$$
\bigcap_{i=1}^{k}F_i=(0,1/k).
$$

Nevertheless,

$$
\bigcap_{i=1}^{\infty}(0,1/i)=\varnothing.
$$

Why? Zero is excluded from every interval. Any positive x eventually fails a test: choose an integer $i>1/x$, making $1/i<x$. Negative x already fails the first test. There is no real number left.

Now include the endpoints: let $G_i=[0,1/i]$. We obtain

$$
\bigcap_{i=1}^{\infty}[0,1/i]=\{0\}.
$$

The same argument removes every positive x, while zero now survives **every** interval. Nonempty finite intersections alone do not guarantee a nonempty infinite intersection; the open-interval example proves that.

## Watch the quantifiers

“Every set has some member” allows the member to change from set to set. “Some member belongs to every set” demands one fixed survivor. Those are different claims. In the open-interval example, you can choose $1/(2i)$ from each $F_i$, but those changing choices do not supply a single number in their common intersection.

## Check your understanding

Find $\bigcap_{i=1}^{\infty}(-1/i,1/i)$. Does the fact that these intervals are open force the intersection to be empty?

The intersection is $\{0\}$. Zero lies strictly between $-1/i$ and $1/i$ for every i. If $x\ne0$, choose $i>1/|x|$; then $1/i<|x|$, and x is outside that interval. Openness alone does not decide the result. What matters is whether a particular outcome belongs to every set.
