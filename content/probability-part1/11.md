# Give uncertainty a vocabulary

The examples have ranged from coin tosses to stock-price paths. To reason about all of them with the same tools, we need a few carefully separated ideas: an experiment, an outcome, a sample space, an event, and a probability assignment.

## Tell the story in five pieces

Take two dice as a running example.

| Term | Role | Example |
|---|---|---|
| Experiment | Procedure whose result we observe | Roll the two labeled dice |
| Outcome | One complete result at the chosen level of detail | $(2,5)$ |
| Sample space | Set of all possible outcomes | All $36$ ordered pairs |
| Event | Collection of outcomes satisfying a question | All pairs whose sum is $7$ |
| Probability | Weight assigned to an event by a model | $1/6$ for sum $7$, with fair independent dice |

The event is not the number $1/6$. It is a set; probability is the numerical weight assigned to that set.

## One outcome can make several events true

For $(2,5)$, the statements “sum is $7$,” “first die is even,” and “second die exceeds $3$” all hold. Events can overlap because the same outcome can satisfy several descriptions.

That observation is why set language is useful. “A or B” collects outcomes in either event; “A and B” keeps their overlap; “not A” collects outcomes outside $A$. The later slides will make these operations precise.

## Start with information, not notation

Before writing a formula, decide what one full outcome records. Are two coin tosses recorded in order, or do we only count heads? Do we record a stock's final price or its full path? There is no universal answer independent of the experiment's purpose.

A useful habit is to write one example outcome in ordinary language, then write the entire space. Only after that should we count favorable cases or draw probability regions. This prevents us from accidentally assigning equal weights to summaries that hide different numbers of underlying outcomes.

## Check your understanding

For two coin tosses, is “exactly one head” one outcome or an event?

<details markdown="1">
<summary>Work through the answer</summary>

If an outcome records the ordered toss sequence, it is the event $\{HT,TH\}$, containing two outcomes. If the experiment records only the number of heads, the recorded value $1$ is one outcome in the reduced space $\{0,1,2\}$. Under independent fair tosses, those three counts have probabilities $1/4,1/2,1/4$, so the reduced outcomes are not equally likely.
