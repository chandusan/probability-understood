# Wait until the first success

Repeat independent Bernoulli trials with the same success probability $p$, where $0<p\le1$. Let $X$ be the trial number on which the first success occurs. We want the distribution of this waiting time.

## Translate X = x into one exact pattern

For the first success to occur on trial $x$, the first $x-1$ trials must all fail and the $x$th must succeed:

$$\underbrace{FF\cdots F}_{x-1\text{ failures}}S.$$

There is only one success/failure pattern satisfying that statement. Independence gives

$$\boxed{P(X=x)=(1-p)^{x-1}p,qquad x=1,2,3,\ldots.}$$

We do not multiply by $\binom{x}{1}$: the position of the success is already fixed at the last trial. Letting it occur earlier would contradict “first success on trial $x$.”

## The event of never succeeding

The probability of failing in the first $m$ trials is $(1-p)^m$. As $m\to\infty$, this tends to zero for $p>0$. Thus the first success occurs in a finite number of trials with probability one, although no fixed finite bound is guaranteed.

If $p=0$, success never occurs and the displayed positive-integer PMF would sum to zero, not one. That is why the ordinary geometric waiting-time model assumes $p>0$.

## Be explicit about the convention

Here $X$ counts **all trials, including the successful one**. Some books or software instead use $Y$, the number of failures before the first success. These satisfy

$$Y=X-1,\qquad P(Y=y)=(1-p)^yp,\quad y=0,1,2,\ldots.$$

The formulas describe the same experiment with a shifted random variable. Stating the support prevents confusing their means, probabilities, or endpoints.
