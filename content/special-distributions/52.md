# Replacement changes the random process

A population contains $N=a+b$ objects: $a$ belong to group A and $b$ to group B. Draw $n$ objects and let $X$ count group-A selections. Compare two experiments: replace each object before the next draw, or keep every selected object out of the population.

## With replacement: each draw starts again

Suppose each draw is uniform and independent of the previous random choices. Replacing the selected object restores the same $N$ objects before every draw. Thus

$$P(\text{A on a specified draw})=p=\frac aN.$$

For an ordered pattern with $x$ A outcomes and $n-x$ B outcomes, independence gives $p^x(1-p)^{n-x}$. There are $\binom nx$ such patterns, so

$$X\sim\operatorname{Bin}(n,a/N).$$

A particular object may appear repeatedly. Consequently, $X$ can exceed the number $a$ of distinct group-A objects: the same A object can be selected more than once.

## Without replacement: the population changes

Assume $n\le N$. If the first draw is A, then

$$P(\text{second A}\mid\text{first A})=\frac{a-1}{N-1}.$$

If the first draw is B, the corresponding probability is $a/(N-1)$. This is the dependence created by removing objects.

Uniform sampling of distinct objects makes every size-$n$ subset equally likely. Count the subsets containing exactly $x$ A objects:

$$X\sim\operatorname{Hypergeom}(N,a,n),\qquad
P(X=x)=\frac{\binom ax\binom b{n-x}}{\binom Nn}.$$

## Same population, different events

For three defective cars among ten and four selections, replacement permits selecting a defective car four times. Without replacement, four defective cars cannot be observed because only three exist.

The event $X=4$ therefore has probability $(3/10)^4$ with replacement and zero without replacement. A shared initial success fraction does not make the complete distributions identical.

<details markdown="1"><summary>Does every draw still have marginal A probability a/N without replacement?</summary>

Yes. Every original object is equally likely to occupy any specified draw position, so the fraction of A objects in that position is $a/N$. Dependence concerns what happens after conditioning on other draws. Equal marginal probabilities do not establish independence.

</details>
