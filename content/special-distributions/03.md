# Define the moment generating function carefully

For a random variable $X$, its moment generating function is $m_X(t)=E[e^{tX}]$, provided this expectation is finite in a neighborhood of $t=0$. The variable $t$ is the input to the function; it is not an outcome of the experiment.

## Calculate it using the distribution of X

For a discrete variable,

$$\boxed{m_X(t)=\sum_x e^{tx}P(X=x).}$$

For a variable with density $f_X$,

$$\boxed{m_X(t)=\int_{-\infty}^{\infty}e^{tx}f_X(x)\,dx.}$$

Both formulas apply the same expectation rule: transform each possible value, then average it with the appropriate probability weights.

For example, if $X=0$ or $1$, with respective probabilities $1-p$ and $p$, then

$$m_X(t)=e^{t\cdot0}(1-p)+e^{t\cdot1}p=1-p+pe^t.$$

The MGF is a function of $t$, while $p$ is a fixed parameter describing this particular distribution.

## What does “the MGF exists” require?

We require some $a>0$ such that $m_X(t)<\infty$ for every $t\in[-a,a]$. Equivalently, finiteness on some open interval containing zero is sufficient; choose a smaller closed interval inside it.

Checking only $t=0$ proves very little, because every random variable satisfies

$$m_X(0)=E[e^0]=E[1]=1.$$

Both positive and negative values of $t$ matter: positive $t$ magnifies a large positive tail, while negative $t$ magnifies a large negative tail.

## What does this assumption buy us?

With an MGF finite around zero, all moments exist and

$$m_X^{(k)}(0)=E[X^k].$$

The existence condition also supports the uniqueness theorem: two distributions with the same MGF on a neighborhood of zero are the same distribution. It is a compact description of an entire distribution, not merely of its mean.
