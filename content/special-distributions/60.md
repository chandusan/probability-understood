# Choose the distribution by describing what is random

Before selecting a formula, finish the sentence “X counts…” and state how the experiment ends. The common discrete distributions encode different random processes, even when their formulas contain similar powers and factorials.

## Ask what is fixed and what is allowed to vary

| Experiment | What $X$ measures | Distribution |
|---|---|---|
| One success/failure trial | Whether success occurs | Bernoulli |
| A fixed number $n$ of independent, identical success/failure trials | Number of successes | Binomial |
| Independent trials until the first success | Trial number of that success | Geometric |
| Independent trials until success number $r$ | Total trials needed | Negative binomial |
| A fixed-size sample without replacement | Number of selected success objects | Hypergeometric |
| Events in a fixed interval under a Poisson model | Number of events | Poisson |
| A fixed number of independent trials with several categories | The vector of category counts | Multinomial |

For binomial and waiting-time models, the success probability must stay fixed across trials. For a hypergeometric model, the population composition is fixed and the sample is uniform among subsets of its size.

## Compare questions that sound similar

“Exactly five wins in 100 plays” fixes the number of plays: use a binomial count under the independent constant-probability model.

“The fifth win occurs on play 100” fixes the target number of wins and asks about stopping time: use a negative binomial. The last play must be a win, so its coefficient is $\binom{99}{4}$, not $\binom{100}{5}$.

“Five winning tickets in a sample of 100 distinct tickets from a finite box” uses hypergeometric counting when tickets are drawn without replacement from a known finite composition.

## Translate the requested event carefully

For integer-valued $X$,

$$P(X\ge k)=1-P(X\le k-1),$$

whereas

$$P(X>k)=1-P(X\le k).$$

The one-unit difference matters for discrete variables. It accounts for the probability mass at $k$.

## Use a final reasonableness check

Check that the event is possible under the support, the answer lies in $[0,1]$, and limiting cases make sense. If sampling the entire finite population still produces an uncertain success count, the selected model is wrong. If the waiting time to the first success can be zero, you are probably using the alternative convention that counts failures instead of total trials.
