# Build the joint model for four treatment outcomes

In the slide's hypothetical treatment model, each patient has probability $0.30$ of complete cure, $0.50$ of reduced pain, and $0.20$ of no change. Apply the treatment to four patients. Let $X,Y,Z$ count those three outcomes. Find their joint distribution and the probability $P(X+Y\ge Z)$.

## State the modeling assumption

To use a multinomial model, assume the four patient outcomes are independent and each has the same three category probabilities. The supplied percentages alone do not establish independence; it is part of the model used for this exercise.

Every patient contributes to exactly one count, so

$$X+Y+Z=4.$$

## Derive the joint probability

One particular sequence with counts $(x,y,z)$ has probability $0.3^x0.5^y0.2^z$. There are $4!/(x!y!z!)$ sequences with those counts. Therefore

$$\boxed{p(x,y,z)=\frac{4!}{x!y!z!}(0.3)^x(0.5)^y(0.2)^z,}$$

for nonnegative integers satisfying $x+y+z=4$, and zero otherwise.

For example,

$$p(1,2,1)=\frac{4!}{1!2!1!}(0.3)(0.5)^2(0.2)=12(0.015)=0.18.$$

## The complete joint distribution

| No change $z$ | Pairs $(x,y)$ in order | Joint probabilities in that order |
|---:|---|---|
| $0$ | $(0,4),(1,3),(2,2),(3,1),(4,0)$ | $0.0625,0.15,0.135,0.054,0.0081$ |
| $1$ | $(0,3),(1,2),(2,1),(3,0)$ | $0.10,0.18,0.108,0.0216$ |
| $2$ | $(0,2),(1,1),(2,0)$ | $0.06,0.072,0.0216$ |
| $3$ | $(0,1),(1,0)$ | $0.016,0.0096$ |
| $4$ | $(0,0)$ | $0.0016$ |

These are the 15 possible count vectors. Each row fixes $Z$ and lists every remaining possibility for $X$ and $Y$.

## Simplify the event before adding

Because $X+Y=4-Z$,

$$X+Y\ge Z\iff4-Z\ge Z\iff Z\le2.$$

The desired event is exactly the first three rows. Add their row totals:

$$0.4096+0.4096+0.1536=\boxed{0.9728}.$$
