# Add the five ways to have at least sixteen successes

Continue the model of twenty independent operations, each successful with probability $0.85$. With $X$ counting successes, we want $P(X\ge16)$. This includes five possible counts: 16, 17, 18, 19, and 20.

## Translate the event before using the formula

These five events are disjoint, so

$$P(X\ge16)=\sum_{x=16}^{20}\binom{20}{x}(0.85)^x(0.15)^{20-x}.$$

The individual terms are:

| Successful operations $x$ | $P(X=x)$ |
|---|---:|
| 16 | 0.182122 |
| 17 | 0.242829 |
| 18 | 0.229338 |
| 19 | 0.136798 |
| 20 | 0.038760 |

Adding the unrounded values gives

$$\boxed{P(X\ge16)\approx0.829847.}$$

Thus the probability is approximately 82.98% under the stated model. The source's $0.8298$ is the corresponding four-decimal approximation.

## Use a complement with the correct endpoint

The complement of “at least sixteen” is “at most fifteen,” so an equivalent expression is

$$P(X\ge16)=1-P(X\le15).$$

Using $1-P(X\le16)$ would instead compute $P(X\ge17)$ and would wrongly omit the probability of exactly sixteen successes.

## A second interpretation using failures

Let $Y=20-X$ count failed operations. Then $Y\sim\operatorname{Binom}(20,0.15)$, and

$$X\ge16\quad\Longleftrightarrow\quad Y\le4.$$

Thus the same answer is $P(Y=0)+\cdots+P(Y=4)$. Switching which category is called success changes the parameter from $0.85$ to $0.15$, but it does not change the physical event.

This is a useful check: two correctly translated descriptions of one event must give the same probability.
