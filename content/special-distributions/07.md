# Derive the MGF of a uniform variable

Let $X$ be uniform on $[0,1]$, meaning its density is $1$ on that interval and $0$ elsewhere. We will calculate $m_X(t)=E[e^{tX}]$, including the value at $t=0$.

## Set up the expectation before integrating

The expectation rule for a continuous variable gives

$$m_X(t)=\int_0^1 e^{tx}\cdot1\,dx.$$

Here integration is with respect to $x$. The symbol $t$ is a fixed number while we carry out that integral.

When $t\ne0$, the chain rule tells us

$$\frac{d}{dx}e^{tx}=t e^{tx}.$$

Consequently, an antiderivative of $e^{tx}$ is $e^{tx}/t$. Applying the endpoints gives

$$m_X(t)=\left[\frac{e^{tx}}t\right]_0^1=\frac{e^t-1}{t},\qquad t\ne0.$$

## Deal with zero using the original definition

Substituting zero into the quotient would give $0/0$, which is undefined. It does not mean that the MGF is undefined. Return to the expectation:

$$m_X(0)=\int_0^1 e^{0x}\,dx=\int_0^1 1\,dx=1.$$

The complete answer is

$$\boxed{m_X(t)=\begin{cases}\dfrac{e^t-1}{t},&t\ne0,\\1,&t=0.\end{cases}}$$

The quotient approaches $1$ as $t\to0$, because $e^t=1+t+t^2/2+\cdots$. The apparent singularity is therefore removable.

## Why it exists for every real t

For $0\le X\le1$, $e^{tX}$ lies between the two finite numbers $1$ and $e^t$. An average of bounded values is finite. Thus the existence condition holds without needing to infer it from the quotient.
