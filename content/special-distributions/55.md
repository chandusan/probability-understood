# Count several categories with a multinomial distribution

Repeat an experiment independently $n$ times. Each repetition produces exactly one of $k$ mutually exclusive and exhaustive categories $O_1,\ldots,O_k$, with fixed probabilities $p_1,\ldots,p_k$ summing to one. Let $X_i$ count how often category $i$ occurs. We want the probability of a complete count vector.

## State the event before calculating

For specified integers $x_1,\ldots,x_k$, the event is

$$\{X_1=x_1,\ldots,X_k=x_k\}.$$

Because every trial contributes to exactly one category,

$$x_i\ge0,\qquad x_1+\cdots+x_k=n.$$

Any vector failing those conditions has probability zero.

## One ordered sequence has a product probability

A particular sequence containing $x_i$ instances of category $i$ has probability

$$p_1^{x_1}\cdots p_k^{x_k}.$$

Independence lets us multiply across trials. Constant category probabilities make every sequence with the same counts have the same probability.

## Count how many sequences have those totals

Choose the positions for category 1, then category 2 from the remaining positions, and continue. This gives

$$\frac{n!}{x_1!\cdots x_k!}$$

sequences. Since distinct ordered sequences are disjoint outcomes, add their equal probabilities:

$$\boxed{P(X_1=x_1,\ldots,X_k=x_k)
=\frac{n!}{x_1!\cdots x_k!}p_1^{x_1}\cdots p_k^{x_k}.}$$

This is the multinomial distribution. A binomial count is the special case with just two categories.

## Independent trials, dependent totals

The trials are independent, but the category counts are generally dependent: $X_1+\cdots+X_k=n$. If all $n$ trials fall in category 1, every other count must be zero.

For one chosen category $i$, each trial is “category i” or “anything else,” so its marginal count is binomial:

$$X_i\sim\operatorname{Bin}(n,p_i).$$

Marginal binomial distributions do not imply that the different category counts are independent.
