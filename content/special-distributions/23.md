# Derive the binomial MGF in two ways

Let $X\sim\operatorname{Binom}(n,p)$, and write $q=1-p$. We want $m_X(t)=E[e^{tX}]$ so that we can derive the mean and variance by differentiation.

## Start from the probability mass function

Apply the discrete expectation rule:

$$\begin{aligned}
m_X(t)&=\sum_{x=0}^n e^{tx}\binom nx p^xq^{n-x}\\
&=\sum_{x=0}^n\binom nx(pe^t)^xq^{n-x}.
\end{aligned}$$

The only rearrangement is $e^{tx}p^x=(pe^t)^x$. We can now recognize the binomial expansion with the two terms $pe^t$ and $q$:

$$\boxed{m_X(t)=(q+pe^t)^n.}$$

It is finite for every real $t$ because $X$ has finite support.

## Derive the same expression from independent trials

Write $X=I_1+\cdots+I_n$, where $I_j$ is $1$ for success on trial $j$ and $0$ for failure. Each $I_j$ has MGF

$$m_{I_j}(t)=q+pe^t.$$

Because the trials are independent,

$$m_X(t)=\prod_{j=1}^nm_{I_j}(t)=(q+pe^t)^n.$$

The first derivation groups outcomes by their final count. The second keeps the independent trials separate until the last step. Both describe the same experiment and reach the same function.

## Check it at zero

$$m_X(0)=(q+p)^n=1.$$

For $n=1$, the result reduces to the Bernoulli MGF, as it should. For $p=0$, it is $1$, the MGF of the constant zero. For $p=1$, it is $e^{nt}$, the MGF of the constant $n$.

The remaining task is calculus: differentiate the complete function $(q+pe^t)^n$, keeping track of the outer power and the inner exponential.
