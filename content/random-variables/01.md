# From random outcomes to numerical values

A random variable is a rule that assigns a number to each outcome of an experiment. This chapter develops that idea into a practical language for probability: describe the numerical quantity we care about, find which outcomes produce its values, and collect their probabilities into a distribution.

## Start with an outcome and a measurement

Roll two dice. One possible outcome is the ordered pair $(2,5)$: the first die shows 2 and the second shows 5. If our quantity of interest is the sum, define

$$X(i,j)=i+j.$$

For that outcome, $X(2,5)=7$. Another outcome, $(3,4)$, also produces the value 7. The random variable keeps the sum and discards some detail about how it arose.

The mapping is fixed before the experiment. What is random is which outcome occurs and therefore which value the mapping produces. We distinguish the uppercase name $X$ from a particular value, such as the lowercase $x=7$.

## Translate a question about numbers back into an event

The statement $X=7$ describes the event

$$\{(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)\}.$$

For independent fair dice, each ordered pair has probability $1/36$. The six listed outcomes are disjoint, so

$$P(X=7)=\frac6{36}=\frac16.$$

By contrast, $X=2$ has only the outcome $(1,1)$ behind it, giving probability $1/36$. Although each die is fair, the possible sums are **not equally likely**. A distribution records these differences.

## Three functions answer different probability questions

| Function | What it tells us | When it is used |
|---|---|---|
| Probability mass function $p(x)$ | $P(X=x)$ | A discrete quantity with countably many values |
| Cumulative distribution function $F(x)$ | $P(X\le x)$ | Any real-valued random variable |
| Probability density function $f(x)$ | Probability accumulated over intervals by integration | A continuous model that has a density |

For a discrete variable, add the masses of the requested values. For a variable with a density, probability comes from area under the density over an interval. The CDF works in both settings by asking how much probability lies at or below a threshold.

These distinctions matter: a density's height at one point is not the probability of that exact value. Later examples will show why a continuous random variable can take a value even though the probability of any one specified value is zero.

## The chapter's examples build the idea in stages

We begin by counting clicks across three ads whose click probabilities depend on the previous response. Then we consider the epoch at which an early-stopping rule is first triggered. These examples show that defining a numerical quantity is separate from assuming a familiar distribution.

The dice example develops a full PMF and its cumulative step graph. A point chosen uniformly in a square then turns distances into geometric events and probabilities into areas. Further exercises connect formulas, graphs, and real questions about counts, spending, and lottery outcomes.

Throughout, use the same sequence: **define the experiment, define the numerical rule, identify the relevant event, and calculate its probability from the stated model.**
