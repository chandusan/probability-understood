# A probability mass function assigns probability to each value

For a discrete random variable $X$, its probability mass function tells us the probability that $X$ equals each specified number. It collects the probabilities of all original outcomes that produce that value. The standard notation is $p(x)=P(X=x)$, where uppercase $X$ is the random variable and lowercase $x$ is the input value we are asking about.

## Read the definition as an event

Let $X$ map outcomes $\omega\in S$ to numbers. For a specified real number $x$,

$$\boxed{p(x)=P(X=x)=P(\{\omega\in S:X(\omega)=x\}).}$$

The set inside the final probability contains all outcomes that the rule maps to $x$. For two dice with $X$ equal to their sum, $x=3$ corresponds to $\{(1,2),(2,1)\}$.

For independent fair dice, each of those outcomes has probability $1/36$, giving $p(3)=2/36$. If the dice were loaded, the same mapping would apply, but we would add the actual probabilities of the two outcomes instead.

Thus a random variable and its PMF are different objects: $X$ maps outcomes to numbers; $p$ maps numbers to probabilities.

## What “discrete” means here

A discrete random variable concentrates all its probability on a finite or countably infinite set of values. “Countably infinite” means the values can be listed in a sequence, such as $0,1,2,\ldots$.

The values need not be consecutive integers. A payout could take values $-1,4,19$, and a transformed count could take values $1,1/2,1/3,\ldots$. What matters is that its probability can be represented by masses attached to individual values.

The PMF is defined for **every real input**. For a dice sum, $p(2.5)=0$ and $p(20)=0$, since neither value can occur.

## Build a small PMF from the original outcomes

Toss two independent fair coins and let $X$ count heads. There are four equally likely outcomes:

| Outcome | $X$ | Outcome probability |
|---|---:|---:|
| $TT$ | 0 | $1/4$ |
| $HT$ | 1 | $1/4$ |
| $TH$ | 1 | $1/4$ |
| $HH$ | 2 | $1/4$ |

Grouping equal values gives

$$p(0)=\frac14,\qquad p(1)=\frac12,\qquad p(2)=\frac14,$$

with $p(x)=0$ otherwise. The two outcomes producing one head contribute to the same mass $p(1)$.

## Two checks every PMF must pass

First, each mass is a probability:

$$0\le p(x)\le1.$$

Second, all masses must sum to one:

$$\sum_x p(x)=1,$$

where the sum runs over the discrete possible values. The events $\{X=x\}$ are mutually exclusive for different $x$, and collectively they contain all possible numerical results.

For a set of values $D$, add the corresponding masses:

$$P(X\in D)=\sum_{x\in D}p(x).$$

For the two-coin count, $P(X\ge1)=p(1)+p(2)=3/4$. This is an event probability assembled from the PMF, not a new mass at the phrase “at least one.”

## Check your understanding

For the two-coin count, what is the difference between $p(1)$ and $P(X\le1)$?

<details markdown="1"><summary>Reveal the reasoning</summary>

$p(1)=P(X=1)=1/2$ counts exactly one head. $P(X\le1)=p(0)+p(1)=3/4$ also includes zero heads. The PMF evaluates equality at one value; cumulative questions add all masses meeting the threshold.
