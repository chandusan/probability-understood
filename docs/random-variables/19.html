Understand probability density · Slide 19

The CDF is the accumulated area under the density

To calculate $F(x)=P(X\le x)$ from a density, shade everything under the density curve to the left of $x$. The source labels that area $F(x)$. The drawn curve is still the density; its shaded area gives one value of the CDF.

~2 min reading/Source + intuition + practice
Let’s understand it

Calculus refresher: integrals, bounds, and the CDF.

Keep the curve and its area separate

The source's curve rises and falls, so it is not itself a CDF graph. A CDF is nondecreasing. The picture should be read as

$$ \text{height of the drawn curve at }t=f(t), \qquad \text{area shaded up to }x=F(x). $$

This distinction matters because both functions describe the same distribution in different ways. The density describes probability per unit near a location; the CDF describes all probability accumulated up to a threshold.

If the threshold moves to the right, the shaded area can only grow or stay the same. Even where the density slopes downward, it remains nonnegative, so moving right still adds area.

Derive the integral formula

The event $X\le x$ includes every possible value below $x$. Applying the density's interval rule over that entire range gives

$$ \boxed{F(x)=\int_{-\infty}^{x}f(t)\,dt}. $$

The lower limit $-\infty$ means “include all the distribution's lower values.” It does not say that $X$ actually takes negative values. If the density is zero below zero, for example, the part of the integral below zero contributes nothing.

The symbol $t$ is a dummy variable that moves through the integration interval. The symbol $x$ is the fixed upper endpoint for the particular CDF value being evaluated. This avoids using the same symbol for two different roles.

Calculate a whole CDF from a simple density

Use the density $f(t)=2t$ for $0\le t\le1$ and zero elsewhere. There are three threshold ranges.

If $x<0$, the integration range has no overlap with the positive-density region, so $F(x)=0$.

If $0\le x\le1$, only the area from 0 to $x$ contributes:

$$ F(x)=\int_0^x2t\,dt=[t^2]_0^x=x^2. $$

If $x>1$, the integral has already included the whole density:

$$ F(x)=\int_0^1 2t\,dt=1. $$

Thus

$$ F(x)= \begin{cases} 0,&x<0,\\ x^2,&0\le x\le1,\\ 1,&x>1. \end{cases} $$

At $x=1/2$, the density height is $f(1/2)=1$, while the accumulated probability is $F(1/2)=1/4$. These quantities are different because one is a height and the other is an area.

Recover an interval from two accumulated areas

For $a<b$, subtract the area up to $a$ from the area up to $b$:

$$ \begin{aligned} F(b)-F(a) &=\int_{-\infty}^{b}f(t)\,dt -\int_{-\infty}^{a}f(t)\,dt\\ &=\int_a^b f(t)\,dt\\ &=P(a<X\le b). \end{aligned} $$

The parts to the left of $a$ cancel. For a density, endpoint probabilities are zero, so the same result applies with either endpoint included or excluded.

Check: what happens where the density is zero?

If $f(t)=0$ throughout an interval, that interval contributes no probability and the CDF stays constant there. A CDF plateau describes an interval carrying no probability; a downward-sloping CDF would violate the accumulation rule.
